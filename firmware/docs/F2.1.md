# F2.1 sensor acquisition

Baseline: `8b6a5464a55a3200a0e4fb921242fa8c563ef5d8`, retaining the
F1.2b-2 pin assignments and provisional calibration in `board_config.h`.
This section supersedes historical statements that the sketch has no sensors.

## Acquisition

`sensors.h/.cpp` implements the sensor module proposed in the integration notes.
`begin()` initializes only sensor pins. `poll()` takes a new snapshot every
2000 ms, starting after a 2000 ms settling period; unsigned elapsed-time
arithmetic tolerates millis rollover. It skips missed periods rather than
performing catch-up reads. The sketch prints each snapshot at 115200 baud.

- Soil: 20 consecutive 12-bit ADC samples on GPIO34, with 11 dB attenuation.
  The fractional average is retained as `soilRawAdc`. Percentage is
  `100 * (3230 - average) / (3230 - 2030)`, clamped to 0–100.
  Invalid ADC codes, all-zero/all-full-scale readings, and reversed/equal
  calibration endpoints invalidate the result. Calibration is provisional.
- DHT11: GPIO27, installed Adafruit DHT sensor library 1.4.7 and its installed
  Adafruit Unified Sensor 1.1.15 dependency. No libraries were installed or
  upgraded. Temperature and humidity calls share the library's cached frame.
  NaN/infinity, temperature outside 0–50 C, or humidity outside 0–100% invalidate
  the pair. These checks do not certify accuracy across that entire range.
- SRF05: GPIO18 TRIG, GPIO19 ECHO. A 10 us trigger and `pulseIn` with a
  30000 us timeout measure pulse width. Distance is `echo_us * 0.0343 / 2` cm.
  Stuck-high ECHO, timeout/zero pulse, and distances outside a provisional
  2–450 cm envelope invalidate the result. Verify that envelope for the actual
  module. There is no tank geometry, water height, or water percentage mapping.

Each acquisition starts with invalid flags and NaN numeric results; failures
never reuse a previous successful value or fabricate zero-valued measurements.
Serial reports averaged raw ADC, percentage, temperature, humidity, raw echo
duration, distance, and three validity flags. Invalid numbers print as `nan`;
an absent echo has duration zero and an invalid distance.

The loop yields for 1 ms. Acquisition is cooperative rather than fully
asynchronous: the DHT library has a short blocking transaction and SRF05 can
block for up to the configured timeout. No long loop delay is used.

## Checks

Host regression tests use Arduino/DHT substitutes; they test production
`sensors.cpp`, not real peripherals or the DHT library's wire protocol:

```powershell
$testBinary = Join-Path $env:TEMP 'watering-f21-sensors-test.exe'
g++ -std=c++11 -Wall -Wextra -Werror -Ifirmware/tests firmware/esp32/sensors.cpp firmware/tests/sensors_test.cpp -o $testBinary
& $testBinary
git diff --check
```

Coverage: 20-sample averaging, calibration endpoints and clamping, ADC rail
and invalid-code failures, DHT nonfinite/out-of-range failures, missing/invalid
echo, stuck-high ECHO, failure recovery, 2-second scheduling and millis rollover.
GPIO mocks reject non-sensor pins and writes other than TRIG. Review of the
sketch and sensor module also confirms there is no relay GPIO access.

Open `firmware/esp32/esp32.ino` directly in Arduino IDE. Its directory contains
`board_config.h`, `sensors.h` and `sensors.cpp`, so no staging or extra include
paths are needed. Host test substitutes stay outside the sketch directory.

## Hardware checklist and limitations

- Disconnect the pump load before testing. GPIO23 remains untouched; this
  preserves the skeleton behavior but cannot guarantee the external relay's
  state during boot/reset or with a floating input. Verify its OFF state.
- Verify the assumed ECHO voltage divider is installed and its output is safe
  for ESP32 GPIO19. Verify sensor supplies, common ground, TRIG compatibility,
  soil AO voltage and DHT DATA pull-up voltage before powering the assembly.
- Confirm pin wiring; inspect Serial at 115200. Observe readings at roughly
  two-second intervals after startup.
- Recalibrate dry/wet soil ADC values with the selected resolution,
  attenuation, supply and installed sensor. Compare known conditions and
  verify percentage direction and clamping. A floating/disconnected ADC may
  look plausible: software range checks cannot reliably detect that fault.
- Compare DHT against a reference; disconnect it and confirm `dht_valid=0`,
  then reconnect and verify recovery without stale data.
- Compare SRF05 against known distances. Remove the target/disconnect ECHO
  and confirm timeout produces `distance_valid=0` while later readings continue.
  Test stuck-high and out-of-range behavior using safe signal levels.
- Confirm relay stays OFF across acquisition, disconnected sensors, boot and
  reset with the pump load disconnected.

No hardware was uploaded, Serial port opened, or pump activated. Compile/host
checks do not verify physical wiring, divider installation, timing on hardware,
sensor accuracy or relay safety. No MQTT, BLE, OTA, backend integration or
F2.2/F2.3/F2.4 behavior is included. The existing OTA documentation storage
